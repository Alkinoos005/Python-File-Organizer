# 📁 File Organizer CLI

A lightweight Python command-line utility to automatically clean up messy directories by organizing files into categorized subfolders based on extension.

# 🚀 Features

- Automated Categorization: Sorts files into `Images`, `Documents`, `Audio`, `Videos`, `Archives`, `Executables`, `Code`, and `Others`.
- Dry-Run Preview: Test what changes will be made without modifying any files.
- Safety First: Ignores hidden files and directories automatically.
- Zero External Dependencies: Built entirely with native Python standard libraries.
